# 🛡️ Скрипт базовой настройки и защиты (Hardening) Linux-сервера

> **Версия:** 2.1  
> **Статус:** Готов к использованию (Production Ready)  
> **Репозиторий:** [thealekseev/vps-setup](https://github.com/thealekseev/vps-setup)

Автоматизированный, идемпотентный Bash-скрипт для безопасной первоначальной настройки и усиления защиты (hardening) свежих серверов под управлением Ubuntu и Debian. Скрипт минимизирует риск человеческой ошибки и закрывает основные векторы атак на новом сервере.

---

## 🌟 Возможности

- ✅ **Идемпотентность:** Скрипт можно безопасно запускать несколько раз, он не сломает уже примененные настройки.
- ✅ **Умное ожидание:** Автоматически ждет разблокировки `dpkg` (критично для свежих VPS, где еще работает `cloud-init`).
- ✅ **Безопасный SSH:** Проверка конфигурации (`sshd -t`) перед перезагрузкой, чтобы не потерять доступ к серверу.
- ✅ **Интерактивность:** Запрашивает подтверждение на критические действия (создание пользователя, смена порта, генерация ключей).
- ✅ **Защита от зависаний:** Создает Swap-файл (2 ГБ) для предотвращения OOM-killer на маломощных VPS.
- ✅ **Комплексная защита:** Настройка UFW, Fail2Ban, sysctl-твики ядра и автоматические обновления безопасности.

---

## 💻 Поддерживаемые ОС

- **Ubuntu:** 20.04 LTS, 22.04 LTS, 24.04 LTS
- **Debian:** 11 (Bullseye), 12 (Bookworm)

> *Примечание: Скрипт может работать и на других deb-based дистрибутивах, но это не гарантируется.*

## 🚀 Быстрый старт

### Вариант 1: Ручная загрузка (Рекомендуется для безопасности)
Всегда рекомендуется проверить содержимое скрипта перед запуском от имени root.

```bash
# 1. Скачайте скрипт
wget -O setup.sh https://raw.githubusercontent.com/thealekseev/vps-setup/refs/heads/main/setup.sh

# 2. Сделайте его исполняемым
chmod +x setup.sh

# 3. Запустите от имени root (или через sudo)
sudo ./setup.sh
